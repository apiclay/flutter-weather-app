# Skycast artwork

Custom artwork generated for this project with built-in image generation. Mechanical size exports were made with FFmpeg. Included project artwork follows the repository's MIT license.

- `app-icon-master.png`: original square artwork.
- `store-icon-512.png`: 512 × 512 PNG for a future store listing.
- `repository-cover.png`: wide README hero.
- `social-preview-1280x640.png`: GitHub repository social preview.

Android launcher resources are installed in `android/app/src/main/res/`, including five legacy densities, an adaptive icon and a branded launch screen. The adaptive foreground is inset to keep the symbol inside Android's safe area. See [Android's adaptive icon guidance](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).

The artwork is branding, not a screenshot or a representation of data returned by ApiClay. Real app screenshots are in the parent `docs` folder.

## Generation prompts

### Icon

Use case: logo-brand. Asset type: final Android launcher icon artwork for the open-source Skycast weather app. Create one exceptionally polished square 1024x1024 icon, full bleed to all four edges, no rounded outer corners and no surrounding mockup. A distinctive sculptural white cloud sweeping upward like an S, with a warm amber sun peeking behind the upper right of the cloud and one small cyan droplet below. Restrained premium 3D product illustration, smooth ceramic/glass materials, precise soft shadows, crisp silhouette readable at 48 pixels. Deep midnight blue to vivid royal blue atmospheric background, subtle cyan illumination. The entire important cloud/sun/droplet symbol must fit inside the central 58 percent of the square so Android circular and squircle crops remain safe. Rich contrast, elegant minimal composition, no tiny details, no text, no letters, no Flutter logo, no border, no watermark. This is the actual finished icon image, not a presentation sheet.

### Repository cover

Use case: ads-marketing. Create a premium 2:1 landscape repository hero cover, 2048x1024, for the open-source Skycast Flutter Android weather app. Reference image is the final Skycast app icon; preserve its distinctive white sweeping cloud, amber sun, cyan droplet and blue identity. Build a beautifully art-directed deep navy and electric blue atmospheric scene with flowing subtle isobars, translucent glass arcs and soft cyan light. Left 55% is a spacious editorial typography layout, right 45% features the icon's cloud/sun/droplet enlarged as a beautifully lit dimensional hero with generous padding. Precisely typeset these exact words: large bold white "Skycast"; beneath in a smaller clean sans-serif "Flutter Weather App"; below "Live data by ApiClay"; a small elegant pill near bottom left "OPEN SOURCE  /  ANDROID". Elegant alignment, excellent readability at GitHub README size, controlled negative space, sophisticated lighting. No terminal, no fake screenshots, no extra text, no Flutter logo, no watermark. All content comfortably inside the canvas. Actual finished cover artwork, not a mockup.
