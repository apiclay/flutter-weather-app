I executed the actual ApiClay.com Weather playground using London. HTTP 200 succeeded. Below are the cURL and the actual JSON. The token is deliberately replaced with a placeholder. Never put it in Flutter, a prompt, logs, or GitHub.

curl -X POST 'https://api.apiclay.com/v1/api/weather/current' \
  -H 'token: YOUR_APICLAY_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"location":"London"}'
